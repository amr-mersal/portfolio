#  Personal Portfolio Website

A clean, responsive **Portfolio Website** built using **HTML5**, **Bootstrap 5**, and **JavaScript**. This site highlights your skills, projects, resume, and contact information — perfect for developers, designers, and freelancers to showcase their work online.

---

##  Live Demo

https://amr-mersal.github.io/portfolio/home.html
---

## Features

-  Hero section with intro and call-to-action
-  About section with profile and biography
-  Skills list 
- Projects section with links and images
-  Resume / CV download button
-  Contact form and social media links
-  Fully responsive design
- Scroll animations and smooth transitions

---

##  Tech Stack

- **HTML5** – Structure and semantic markup
- **Bootstrap 5** – Responsive grid and components
- **JavaScript (Vanilla)** – Interactivity and animations
